# PulseSelect ProxBox 3D model (unofficial)

An interactive 3D model of the PulseSelect™ ProxBox™ pulsed field ablation adapter, modelled from
photographs. It is not produced or endorsed by Medtronic. The unit's serial number and QR code are
not reproduced.

Open https://imh097.github.io/proxbox/ in Safari on an iPhone or iPad, then use Share › Add to Home
Screen. After that first visit it opens from the Home Screen like an app, with no internet connection.

`ProxBox.epub` is the same viewer as a one-page book for Apple Books.
